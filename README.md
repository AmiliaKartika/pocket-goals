# Pocket Goals

Aplikasi sederhana untuk membantu pengguna mengelola target keuangan dan memantau progres tabungan.

## 🚀 Features

- Tambah Goal
- Edit Goal
- Hapus Goal
- Progress Bar
- Due Date
- Local Storage
- CRUD Transaction
- Responsive UI

## 🛠 Tech Stack

- HTML
- Tailwind CSS
- JavaScript
- Local Storage
